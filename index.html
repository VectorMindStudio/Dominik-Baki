Gründer von byte & HandwerkDigitale Lösungen ausgehend von realen Arbeitsabläufen.

Was mich antreibt

Code ist für mich kein Selbstzweck.

Mich reizt der Moment, in dem aus einer zunächst unklaren Idee ein Werkzeug wird, das Menschen im Alltag wirklich unterstützt. Dafür muss ich zuerst verstehen, wo Zeit verloren geht, welche Entscheidung schwerfällt und was eine Lösung tatsächlich leisten soll.

Meine beruflichen Stationen wirken auf den ersten Blick unterschiedlich. Für meine heutige Arbeit ergeben sie ein klares Muster: sorgfältig beobachten, komplexe Abläufe strukturieren, Verantwortung übernehmen und Ergebnisse so umsetzen, dass sie praktisch funktionieren.

Unter byte & Handwerk übertrage ich diese Arbeitsweise auf digitale Produkte. Die Branche kann wechseln. Die Methode bleibt.
