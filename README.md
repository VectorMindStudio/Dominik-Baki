# Interaktiver Lebenslauf – Dominik Baki

Diese Webseite ist eine moderne, interaktive Darstellung meines beruflichen Profils und Lebenslaufs.

Der Schwerpunkt liegt auf meiner aktuellen Positionierung als Native iOS App Developer, meinen technischen Kompetenzen, ausgewählten App-Projekten sowie meinem beruflichen Hintergrund aus Lebensmittelhandwerk, Biotechnologie, GMP-Produktion und Vertrieb.

Die Anwendung ist vollständig responsiv und für Desktop, Tablet und Smartphone optimiert.

## Funktionen

### Profil und Positionierung

Der Einstiegsbereich zeigt:

* Name und aktuelle berufliche Positionierung
* fachlichen Schwerpunkt
* Kontaktdaten
* GitHub- und LinkedIn-Profil
* Standort
* kompakte berufliche Zusammenfassung

Der Lebenslauf positioniert mich als Entwickler nativer iOS-Anwendungen mit Fokus auf:

* Swift

* SwiftData
* Firebase
* Firestore
* MapKit

* Clean Architecture
* nutzergetriebene MVP-Entwicklung

### Technische Kompetenzen

Die technischen Fähigkeiten werden nach Themenbereichen strukturiert dargestellt:

* iOS-Entwicklung
* Android-Entwicklung
* Backend und Datenhaltung
* Softwarearchitektur und Delivery
* Produktentwicklung und Zusammenarbeit

Auf künstliche Prozentangaben oder selbst vergebene Kompetenzbewertungen wird bewusst verzichtet. Stattdessen werden Technologien und Methoden aufgeführt, die in Ausbildung, Projektarbeit und Pilotanwendungen praktisch eingesetzt wurden.

Der Projektbereich stellt aktuelle und abgeschlossene Arbeiten vor:

Die Projekte enthalten jeweils:

### Beruflicher Werdegang

Der berufliche Werdegang wird als interaktive Zeitleiste dargestellt.

Die einzelnen Stationen können angeklickt und erweitert werden. Dadurch bleiben frühere Tätigkeiten kompakt, während bei Bedarf detaillierte Informationen eingeblendet werden.

Enthalten sind unter anderem Erfahrungen aus:

* App-Entwicklung und eigenen Produktprojekten
* Vertrieb und Kundenberatung
* pharmazeutischer Produktion
* GMP-regulierten Arbeitsumgebungen
* Prozessentwicklung und Prozessübertragung
* Biotechnologie
* Lebensmittelhandwerk

### Sprachumschalter

Die wichtigsten Inhalte können zwischen Deutsch und Englisch umgeschaltet werden.

Die gewählte Sprache wird lokal im Browser gespeichert und beim nächsten Aufruf automatisch wiederhergestellt.

### Dark Mode

Die Webseite unterstützt einen hellen und einen dunklen Darstellungsmodus.

Der Dark Mode kann über das Sonnen- beziehungsweise Mond-Icon im Header aktiviert werden. Die Auswahl wird ebenfalls lokal im Browser gespeichert.

### Responsive Design

Die Darstellung passt sich automatisch an unterschiedliche Bildschirmgrößen an.

Die Webseite ist optimiert für:

* Desktop
* Tablet
* Smartphone

### Druckansicht

Für Bewerbungen oder Archivierung kann die Seite über die Druckfunktion des Browsers ausgegeben beziehungsweise als PDF gespeichert werden.

Navigationselemente und Bedienelemente werden in der Druckansicht automatisch ausgeblendet.

### Nutzung

Die Navigation erfolgt über die Menüleiste am oberen Rand der Webseite.

Über die Navigation können folgende Bereiche direkt aufgerufen werden:

* Profil
* Kompetenzen
* Projekte
* Beruflicher Werdegang
* Ausbildung

Im Bereich Beruflicher Werdegang lassen sich die einzelnen Einträge anklicken, um zusätzliche Informationen ein- oder auszublenden.

Die Sprache und das Farbschema können über die Bedienelemente im rechten Bereich des Headers geändert werden.

### Technischer Aufbau

Die Webseite basiert auf einer einzelnen HTML-Datei und verwendet:

* HTML5
* Tailwind CSS
* Vanilla JavaScript
* Font Awesome
* Local Storage
* Google Fonts

Es wird kein Framework und kein eigenes Backend benötigt.

### Projektstruktur

/
├── index.html
└── README.md

Lokal ausführen

Da die Anwendung vollständig clientseitig arbeitet, kann die Datei direkt im Browser geöffnet werden.

Alternativ kann ein lokaler Entwicklungsserver verwendet werden.

Beispiel mit Visual Studio Code und der Erweiterung „Live Server“:

1. Repository klonen oder herunterladen
2. Projektordner in Visual Studio Code öffnen
3. index.html auswählen
4. „Open with Live Server“ starten

### Hosting mit GitHub Pages

Die Webseite kann direkt über GitHub Pages veröffentlicht werden.

Vorgehensweise

1. Repository auf GitHub erstellen
2. index.html und README.md hochladen
3. In den Repository-Einstellungen den Bereich Pages öffnen
4. Als Quelle den gewünschten Branch auswählen
5. Root-Verzeichnis / verwenden
6. Änderungen speichern

Die veröffentlichte Webseite ist unter https://dominikbaki.com/ erreichbar.

### Datenschutz

Die Webseite verwendet kein externes Backend und sendet keine eingegebenen Daten an einen eigenen Server.

Die gewählte Sprache und das bevorzugte Farbschema werden ausschließlich lokal im Browser gespeichert.

Externe Ressourcen wie Tailwind CSS, Font Awesome und Google Fonts werden über Content Delivery Networks geladen.
