# Dominik Baki – persönliche Profilseite

Statische Profilseite unter [dominikbaki.com](https://dominikbaki.com/).

Die Seite übernimmt das visuelle System von byte & Handwerk und verbindet persönliche Positionierung, Arbeitsweise, Projekte, beruflichen Hintergrund und nachgewiesene Qualifikationen.

## Inhalte

- persönliche Positionierung und Arbeitsweise
- ausgewählte Projekte: RevierHege, TreueBiss und EmigrateIn
- technische Kompetenzen für iOS, Android, Backend und Produktentwicklung
- beruflicher Hintergrund aus Handwerk, Biotechnologie, regulierter Produktion und Vertrieb
- Qualifikationen aus den vorliegenden Zertifikaten und Modulabschlussbewertungen

## Umgang mit Nachweisen

Die Originaldokumente werden nicht im öffentlichen Repository abgelegt. Mehrere Nachweise enthalten Geburtsdatum, Unterschriften und weitere persönliche Angaben. Auf der Webseite werden deshalb ausschließlich überprüfte Qualifikationsangaben zusammengefasst.

## Technischer Aufbau

- statisches HTML5
- eigenes responsives CSS ohne externe Bibliotheken
- kleines Vanilla-JavaScript für die mobile Navigation und Jahreszahl
- strukturierte Person- und Qualifikationsdaten nach Schema.org
- `robots.txt` und XML-Sitemap für Suchmaschinen
- GitHub Pages mit eigener Domain über `CNAME`
